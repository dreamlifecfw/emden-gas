خطوات النشر

1) Firebase
- ادخل console.firebase.google.com وسوِّ مشروع جديد (Add project).
- من Build > Firestore Database اضغط Create database، واختر Production mode وأقرب منطقة.
- من تبويب Rules الصق محتوى ملف firestore.rules واضغط Publish.
- من Project settings (أيقونة الترس) > Your apps اضغط أيقونة الويب </> وسجّل تطبيق، وانسخ كود firebaseConfig.

2) الملف
- افتح index.html والصق قيم firebaseConfig مكان كلمة PASTE_HERE.

3) GitHub
- سوِّ Repository جديد (Public).
- Add file > Upload files وارفع index.html واضغط Commit.
- Settings > Pages > Source: Deploy from a branch > main / (root) > Save.
- بعد دقيقة يطلع رابط الموقع.
